# Дизайн-система приложения «Задачник» (Design System)

Документация описывает ключевые элементы дизайн-системы, созданной в рамках лабораторных работ по разработке под Android (Material 3).

## 1. Цветовая палитра (Color Palette)
Приложение поддерживает световую (Light), темную (Dark) темы, а также динамические цвета (Dynamic Color) для устройств с Android 12+ (SDK >= 31).

- **Primary**: Фиолетовые оттенки (`#6750A4` для Light, `#D0BCFF` для Dark). Используется для основных кнопок, активных элементов и акцентов.
- **Surface**: Цвет подложек и карточек (`#FEF7FF` для Light, `#141218` для Dark).
- **Surface Variant**: Цвет второстепенных контейнеров (`#E7E0EC` для Light, `#49454F` для Dark).
- **Error**: Красный цвет для критических состояний и ошибок (`#E53935`).

## 2. Типография (Typography)
Используются стандартные шрифты Material 3 со следующими модификациями:
- **headlineMedium**: Полужирный (Bold), размер 28.sp, межстрочный интервал 36.sp. Применяется для главных заголовков экранов.
- **bodyLarge**: Обычный (Normal), размер 16.sp, межстрочный интервал 24.sp. Применяется для основного текста, описаний и блоков статистики.

## 3. Формы (Shapes)
Скругления элементов стандартизированы через Material 3 Shapes:
- **small**: Скругление 8.dp (чипсы, мелкие кнопки).
- **medium**: Скругление 16.dp (карточки задач, `ProfileCard`).
- **large**: Скругление 24.dp (диалоговые окна, большие контейнеры).

## 4. Компоненты (Components)

### AppButton
Универсальная кнопка с поддержкой стилей и размеров:
- **Стили (ButtonStyle)**: `PRIMARY` (основная), `SECONDARY` (второстепенная), `OUTLINED` (контурная).
- **Размеры (ButtonSize)**: `SMALL`, `MEDIUM`, `LARGE`.
- Автоматически адаптирует цвета текста и контейнера из `MaterialTheme.colorScheme`.

### ProfileCard
Карточка профиля со слотами:
- Принимает слоты `leadingIcon` (иконка слева), заголовок, подзаголовок и `trailingContent` (элементы справа, например, кнопка редактирования).
- Использует форму `medium` и цвета `surfaceVariant` / `onSurfaceVariant`.

### LoadingButton
Кнопка с индикатором загрузки:
- При состоянии `isLoading = true` блокирует нажатия и отображает `CircularProgressIndicator` вместо текста.

## 5. Доступность (Accessibility)
- **Слияние узлов**: Компонент `ProfileCard` использует `Modifier.semantics { mergeDescendants = true }`, чтобы программы чтения экрана воспринимали содержимое карточки как единую смысловую единицу.
- **Динамические регионы (Live Regions)**: Уведомления об успешном сохранении изменений используют `Modifier.semantics { liveRegion = LiveRegionMode.Assertive }` для немедленного озвучивания скрин-ридерами.
